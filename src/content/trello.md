# Fallen Lineage Official Trello Directory

The official Trello board is the primary documentation hub maintained by the Fallen Lineage development team. Unlike automated wiki scrapers, the Trello board provides direct, unfiltered insight into developer roadmaps, mechanic formulas, upcoming balance changes, and known bug trackers.

## How to Access the Official Board

Developers host their public board directly on Trello. When accessing third-party links, always verify that the board administrator matches the verified creator group inside Roblox:

- **Official Trello Board URL**: Check the pinned announcements on the [Official Discord](#official-discord-community) or Roblox game description page.
- **Access Rule**: The board is read-only for public members; you do not need a Trello login to view cards, attachments, or upcoming milestone columns.

## What Each Trello Column (List) Represents

A well-structured Trello board organizes game systems into logical, left-to-right columns. In Fallen Lineage, expect to navigate the following lists:

1. **Information & FAQ**: The leftmost column detailing server rules, community managers, official Roblox group links, and core game terminology.
2. **Upcoming Content / Roadmap**: High-priority features currently in sprint cycles, such as new dungeon biomes, class reworks, or item tiers planned for the next major patch.
3. **In-Progress Work**: Live cards showing mechanics being coded, tested in private build servers, or awaiting visual assets.
4. **Class Directory & Skills**: Deep-dive cards for each character archetype containing raw formula values, scaling multipliers, and unlock conditions.
5. **Weapons, Relics & Consumables**: Comprehensive stat blocks and drop rates for dungeon loot tables.
6. **Bugs & Known Glitches**: Tracked issues acknowledged by developers alongside planned hotfix ETAs.

## How to Track Updates Using the Trello Board

To stay ahead of the game economy and meta tier shifts:
- Look for the **"Activity"** tab or recently updated card badges (labeled with timestamps).
- Check the **"Patch Candidates"** card before every weekend update to see which classes are receiving damage buffs or cooldown adjustments.
- Compare mechanic notes with our [Tier List](/tier-list) to prepare builds before patches go live on Roblox.

## Official Discord Community

In addition to Trello, the community Discord server offers real-time voice lobbies, guild recruitment, and developer Q&A sessions:
- Always join only via the official game page social links inside Roblox to prevent phishing attempts.
- Turn on notifications for the `#announcements` channel to catch newly released [Codes](/codes) within seconds of publication.
